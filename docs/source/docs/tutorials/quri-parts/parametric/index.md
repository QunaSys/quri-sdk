This tutorial aims to introduce parametric states and parametric estimators, which are also important building blocks of variational algorithms.

### [Gradient Estimators](gradient_estimators.ipynb)

One of the most important elements of optimization algorithms is computing the gradient of a physical observable with respect to a set of circuit parameters. This tutorial introduces the gradient estimators QURI Parts provides.
