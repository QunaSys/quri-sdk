# Quration Resource Estimation

Compile qsub circuits for surface-code and lattice-surgery architectures, then estimate their FTQC resources with Quration.

## Contents

### [Basic Resource Estimation](basic_resource_estimation.ipynb)

Convert a logical CNOT circuit to Quration IR, compile it to the target instruction set, and inspect its resource profile.

### [Multiple-Circuit Resource Estimation](multiple_circuit_resource_estimation.ipynb)

Compare QPE resource profiles while varying the number of phase-readout qubits.
