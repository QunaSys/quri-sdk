# Circuit Compilation

How to convert circuits between gate sets and reduce their cost.

## Contents

### [Transpile a Circuit](transpiler.ipynb)

Convert a circuit to a semantically equivalent one, e.g. for a device gate set.

### [Compile Circuits Variationally (QAQC)](quantum_circuit_compilation.ipynb)

Approximate a deep circuit by a fixed-depth variational circuit.

```{note}
Circuits described with the [qsub DSL](../../tutorials/quri-parts/qsub.ipynb)
can also be compiled and analyzed; see the qsub tutorial under QURI Parts.
```
