# Applying Algorithms

End-to-end worked guides that apply QURI SDK algorithms to concrete problems.
Use them as starting points to adapt to your own research.

```{note}
Learning how a textbook algorithm works (QFT, QPE, and more)? See
[Quantum Algorithms](../../reference/quantum_algorithms/index.md) in the reference.
```

## Contents

### [Quantum Selected Configuration Interaction (QSCI)](quantum_selected_configuration_interaction.ipynb)

Apply QSCI to a chemistry problem in the context of early fault-tolerant quantum computing.

### [Statistical Phase Estimation](statistical_phase_estimation.ipynb)

Execute statistical phase estimation using QURI Algo and QURI VM.

### [Transverse-field Ising Model](transverse_field_ising_model.ipynb)

Approximate the TFIM ground state with VQE and improve it with SPE and QSCI.

### [Scalar Field Theory](scalar_field_theory.ipynb)

Simulate lattice scalar field theory on a quantum computer.

### [Black Hole Evaporation (Page Curve)](page_curve.ipynb)

Use qsub to simulate the Page curve of an evaporating black hole.
